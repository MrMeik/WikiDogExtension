# Firefox Desktop

## First Installation

1. Find the latest firefox release from the [releases section](https://github.com/MrMeik/WikiDogExtension/releases) on Github. It will have a `.xpi` extension and be listed under the for the latest release `assets dropdown`.
2. When you click on the `extension-firefox.xpi` you will be prompted to install the add-on, click `continue to installation` and the `add` on the following screen
3. Once this is done, click the `extensions icon` ![manage extensions icon](./assets/firefox-desktop/manage-extensions.png) and naviate to the extensions page by clicking `manage extentions` at the bottom of the menu.
4. Naviate down to the WikiDog extension and click the `...` button. In that menu, select the `options` selection. This will bring to you a page prompting you to enter your extensions API key.
5. Paste in your token and click `Save token` to complete setup.
6. Refresh your DogOnline page and your gameplay statistics will now be reported automatically.
